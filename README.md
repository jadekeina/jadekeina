## 🔐 Cybersecurity Projects

🛡️ **Mini-SOC with Wazuh**: 3-VM lab (Wazuh server on Ubuntu, Debian victim, Kali attacker). I simulated an SSH brute-force attack with Hydra and detected it in Wazuh through correlation rules 5763 (*brute force trying to get access*) and 40112 (*multiple authentication failures followed by a success*).

🏢 **Active Directory Mini-Company**: Windows Server 2022 domain controller (AD DS, DNS, DHCP), organizational units per department (IT, HR, Finance, Sales), and a PowerShell script that bulk-creates users and groups from a CSV file.

🔎 **Pentest: Target Machine Audit**: from passive recon (Shodan, TheHarvester) to active scanning (Nmap, Gobuster, Wfuzz, Nikto). Found missing security headers, internal IP disclosure, directory listing and an outdated Apache version (2.4.18), then built an impact/probability risk matrix.

🧱 **WAF for SecureShop (team project)**: ModSecurity WAF deployment for an e-commerce site. My role was project owner (MOA), in charge of requirements analysis.

📑 **ISO 27001 ISMS (team project)**: helped bring a fictional organization into ISO 27001 compliance. I wrote the Statement of Applicability (SoA).

🌐 **Network Infrastructure Simulation**: multi-VM setup with routing and DNS/DHCP, plus segmented LANs and firewalling with iptables/UFW.
